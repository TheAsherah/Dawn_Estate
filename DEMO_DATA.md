## 🎯 Testing Workflow

### For Regular Users:
1. Register a new account
2. Login
3. Browse properties
4. Add a new property listing
5. Wait for admin approval
6. Request an estimation

### For Admin:
1. Login with admin account
2. View dashboard statistics
3. Approve/reject pending properties
4. Manage users (promote user to admin)
5. Review estimation requests
6. Delete unwanted content

## 🌍 Testing Multilingual

1. Change language in navbar (EN/FR/AR)
2. Notice all content translates
3. Test RTL layout with Arabic
4. All forms work in any language

## 📱 Testing Responsive

1. Open on mobile device
2. Use sidebar navigation
3. Test filters on mobile
4. Check property cards layout
5. Test form submissions

## 🎨 Color Scheme

The platform uses:
- **Primary**: Amber/Gold (#b45309, #92400e)
- **Backgrounds**: White, Light Gray
- **Text**: Dark Gray, Black
- **Accents**: Amber gradients

## 🔄 Property Status Testing

1. User creates property → Status: **Pending**
2. Admin sees it in dashboard
3. Admin clicks **Approve** → Status: **Approved**
4. Property now visible on public pages
5. Or admin clicks **Reject** → Status: **Rejected** (hidden)

## 📊 Dashboard Metrics

After adding demo data, you should see:
- Total Users: 3+ (admin + test users)
- Total Properties: 5+ (sample properties)
- Pending Properties: Varies
- Approved Properties: Varies
- Total Estimations: 2+ (sample requests)

## 🚀 Quick Demo Script

**5-Minute Demo:**

1. **Homepage** (30s)
   - Show hero section
   - Scroll to recent properties
   - Click language switcher

2. **Properties** (1m)
   - Open properties page
   - Apply filters (villa, sale, pool)
   - Click on a property

3. **Property Detail** (1m)
   - Show gallery
   - View features
   - Click WhatsApp button

4. **Add Property** (1m)
   - Fill form
   - Upload image
   - Submit

5. **Admin Dashboard** (1m 30s)
   - Login as admin
   - View statistics
   - Approve property
   - Manage users

## 🎭 Demo Tips

- Use **lorem ipsum** for descriptions if needed
- Keep prices realistic for Moroccan market
- Use real city names: Casablanca, Rabat, Marrakech, Tangier, Agadir
- Surface typically: Studios 30-50m², Apartments 80-200m², Houses 200-500m², Villas 400-1000m²
- Common prices:
  - Studio rent: 2,500-5,000 MAD
  - Apartment rent: 5,000-20,000 MAD
  - Villa sale: 3,000,000-20,000,000 MAD
